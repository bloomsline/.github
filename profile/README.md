# Bloomsline

Bloomsline helps mental-health practitioners run their practice and stay with their patients between sessions.

- **Bloomsline Care** — practice management for practitioners: patients, scheduling, notes and sessions.
- **Bloomsline app** — the patient companion, for moments, mood and the work between appointments.

We handle health data, so security and privacy come first in everything we build.
